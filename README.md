An e-commerce web application for selling home appliances, developed using ASP.NET MVC and SQL Server.

## Features
- User authentication (Register/Login)
- Product browsing and searching
- Shopping cart and checkout
- Order management
- MoMo Sandbox payment integration
- Gemini AI chatbot support
- Admin dashboard for product and order management

## Technologies Used
- ASP.NET MVC
- C#
- SQL Server
- Entity Framework
- Bootstrap
- MoMo Sandbox API
- Gemini API
